# 续费统计 Skill

自动汇总语文、数学、英语三科续费数据，生成"幼小拼音汇总"和"总体合计汇总"两张报表。

## 功能

- 支持三科（语文/数学/英语）续费数据自动汇总
- 支持小高综合续班数据合并（素养E→英语，素养M→数学）
- 自动按续费率降序排列
- 保留 0.5 等非整数续费值
- 单文件/双文件模式自适应
