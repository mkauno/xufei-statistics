# 续费Skill原始规则全文

> 来源：E:/工作稿/2026.5/续费skill.xlsx，录入日期：2026-05-13

## 基本信息

| 字段 | 内容 |
|------|------|
| 用途 | 以后用户说"统计续费"时，自动按本流程汇总语文、数学、英语的基数和续费数据。 |
| 触发语句 | 统计续费 / 汇总续费 / 续费统计 / 做续费表 |
| 数据来源 | 语文、数学、英语三个原始数据表 |
| 关键字段 | 上课校区、课程年级、任课老师、基数、是否续费3季度 |
| 统计口径 | 基数=sum(基数列)；续费=sum(是否续费3季度列)；空值按0处理；保留0.5等半数续费。 |

## 步骤

1. 读取语文/数学/英语表头，确认字段位置。
2. 生成"幼小拼音汇总"：筛选语文幼小、语文拼音、数学幼小、英语幼小。
3. 在"幼小拼音汇总"中输出总体汇总、各分组教师汇总、校区汇总。
4. 生成"总体合计汇总"：使用三科全量数据，不按年级筛选。
5. 在"总体合计汇总"中输出总体数据、校区汇总、语文教师汇总、数学教师汇总、英语教师汇总。
6. 各汇总区块按续费率从高到低排列；续费率=续费/基数；续费率相同时再按基数降序。
7. 续费列格式：整数不显示小数点；含0.5等非整数保留1位小数。
8. 设置标题、表头、数字格式、列宽，并检查空表头和错误值。

## 输出表

| 输出表 | 表名 | 内容 | 格式 |
|--------|------|------|------|
| 输出表1 | 幼小拼音汇总 | 语文-幼小 / 语文-拼音 / 数学-幼小 / 英语-幼小 | 含续费率，按续费率降序 |
| 输出表2 | 总体合计汇总 | 语文 / 数学 / 英语全量总体、校区、分学科教师 | 含续费率，按续费率降序 |

## 格式规则

| 列 | 格式 | 说明 |
|----|------|------|
| 基数列 | #,##0 | 整数显示 |
| 续费列 | 整数：#,##0；非整数：#,##0.0 | 避免显示222.这种尾点 |
| 续费率列 | 0.0% | 所有汇总表均需要 |

## 校验清单

1. 总体合计=语文+数学+英语。
2. 各校区汇总按三科全量合并。
3. 教师汇总必须分语文、数学、英语分别输出。
4. 续费列整数无小数，0.5保留。
5. 无空表头、无#REF/#DIV/0/#VALUE等错误。
